# ST-Orange-ThemeStudio 手机隔离测试版

版本 0.15.8-avatar-area.0。面向 SillyTavern 1.18.0；电脑和手机使用同一个插件。

## 安装
在酒馆扩展管理中选择「安装扩展」，粘贴：

https://github.com/yanxu-orange/ST-Orange-ThemeStudio-test

如已安装正式 ThemeStudio，先导出方案备份、停用正式版并刷新，再启用此测试版。两个版本不可同时启用。

本测试版使用独立保存键 `orange.theme-lab.mobile-test.v1`，不会读取或覆盖正式版保存。可用 JSON 导入/导出方案，跨设备不会自动同步。

161 项自动检查通过。本批已做 DOM、手势事件和数值计算回归，浏览器视觉检查因隔离环境限制未完成；尚未完成真实酒馆、手机视觉与触摸验收。请勿作为稳定发布版使用。

手机底栏切换预览/区域/调整/素材。点击预览中的素材或可定位文字选中，再拖动位置；选中的素材可双指缩放。空白处和未选中的内容用于滚动，图层列表与数值可精调。头像、正文整体不参与自由拖动。修改后需主动保存。

内置素材及字体许可随仓库提供。

## 手机流程更新

手机打开先选择继续草稿、导入、模板或无装饰起稿。顶部工具收成靠右悬浮入口，展开后提供作品、撤销、保存、应用、退出、更多；底栏重复点选可收起面板。返回作品不会重置草稿，无装饰起稿须确认替换且不会自动保存。

无装饰起稿仍使用工具基础布局与颜色，并非恢复酒馆原生样式。桌面沿用原布局。保存键与 schema 10 不变。

## 隐藏滚动条

手机「更多 → 方案 → 隐藏滚动条（仍可滚动）」；桌面在「方案」菜单。旧方案缺省开启，关闭可恢复原有样式；保存方案才保留选择。

作用于工作台及应用期间的酒馆原生滚动条，并适配已识别的兰台开放 shadow 面板。不覆盖其他未知或封闭 shadow、iframe、独立 App 及自绘滚动条。不禁用滚动，不修改其他插件源码；退出后清理自有临时样式。

真实手机滚动和绘制效果尚待验收。

## 配色与酒馆背景

新增工具内配色面板，确认后才提交本次颜色修改。

新方案透出酒馆当前背景，不另设画布背景色或图片；请在酒馆背景菜单换图。卡片底色、透明度和玻璃模糊独立保留。跨设备导入不会携带酒馆壁纸。

旧方案保留原纯色画布，可在整体区域点击「改为跟随酒馆背景」，支持撤销，保存后记住。未进行真实手机视觉验收。

## 文字与位置控件整理

头像区基础页面不再展示文字整体对齐和整体偏移控件，名字、时间、自定义文案仍可独立编辑；旧方案已有整体偏移保持不变。

位置数值旁新增减/加微调按钮，按原步长移动并支持逐次撤销。层次按钮改为「上移一层 / 下移一层」，仅改变叠放顺序，不改变画面位置。本次沿用版本号，以仓库提交区分更新。

## 预览文字整理

移除预览顶部说明条，统计示例改为简洁的楼层、耗时、token 和翻页数值。只改变工作台虚构预览，不写入真实聊天记录，不修改真实消息统计。

## 预览与应用样式一致性修复

统一思维入口的预览/真实聊天布局规则，并调整输入区样式一致性。仅更改插件自己的样式与适配代码，不修改真实消息内容或用户保存数据；真实手机视觉仍待验收。

## 手机数值步进

窄屏（700px及以下）数值项改用减号、数字、加号和步长选择；可以手工输入，步长为该项基础步长的1/5/10倍。原范围与配置格式不变，每次点击支持单独撤销。宽屏保留原滑条和已有位置微调按钮。真实手机触摸和布局仍待验收。


## 头像设计整理（0.15.5-avatar-design.0）

头像区 → 头像设计先选「统一设计 / 分别设计」，分别设计时切换 AI / 用户。选择统一设计会以当前正在设计的一侧同步两侧设置，可撤销；预览图片仍各自独立。铺满、普通显示与头像边框属于外观设置；铺满时只显示取景和渐变，隐藏尺寸、边框与变换。普通头像支持独立大小、圆角、位置与变换，普通和铺满都能调整取景。头像区小排版模板已移除，头像原点不再随局部排版改变；名字、时间与文案仍自由摆放。

打开编辑器时一次读取当前聊天中最后一条 AI 和用户消息的头像，不持续观察；不可用时使用默认图。可在折叠的「预览图片（仅本次）」内选择 PNG/JPG/WebP，先显示图片再调取景，无 2 MiB 限制。预览图只留在本次编辑会话，不进入保存或导出；退出编辑后清除本次预览引用。应用仍使用酒馆原生头像。

共用文案改为「全局设计 / 整体样式 / 全局装饰 / 操作与统计」；未接入快捷回复禁用，提示短暂显示。区域、消息卡片与头像边框粗细支持 0.25 px 步长及小数输入。PC 和手机继续使用同一方案数据、各自布局，不涉及跨设备自动同步。

开发验证：`npm ci && npm test`。新增完整回归测试源以便复验；本批云电脑隔离宿主检查桌面和 390×844 手机尺寸，不能代替真实酒馆和真机触摸验收。尚未进行真实手机测试。


## 卡片预览与操作定位（0.15.6-preview-controls.0）

全局设计 → 整体样式增加「卡片宽度：限制最大宽度 / 铺满聊天区」和「卡片两侧留白」。选择铺满、留白设为 0 后，卡片两侧贴到聊天区内边缘；卡片内部留白保持独立。预览和应用共用留白与宽度规则，预览外框继续保留作为聊天区域参考。

打开编辑器前读取当前聊天区宽度；预览在可用空间内尽量使用该宽度。窄屏开关只缩小预览外框，不再强制卡片为 390 px，也不覆盖用户设置的卡片最大宽度。桌面侧栏和手机屏幕不足时，按实际可用宽度缩小，不代表真实宿主完全等宽。

思维入口的小箭头默认隐藏，可切换显示。入口文字新增独立水平、纵向位置，只移动文字，不移动入口背景和箭头。操作与统计 → 操作位置可选头像区或尾部；头像区支持顶部、居中、底部定位，并保留上下微调。尾部继续按实际尾部高度定位。预览中的编辑／更多补齐按钮样式类与显示规则，仅影响虚构预览，不强行显示真实宿主关闭的按钮。实际宿主中隐藏更多的具体规则仍未确认。

本批不做旧方案迁移。更新前请先导出旧测试方案备份；缺少本批思维入口或操作锚点字段的方案不会载入。正式版保存和正式仓库未改动。

开发验证：`npm ci && npm test`，136 项通过，另通过模块语法及 diff 检查。覆盖 1600 / 1200 / 390 / 320 px 的宽度计算、0 留白与铺满、保存/撤销/导出、入口位移与箭头切换、高头像区按钮定位、尾部增长及退出重开。浏览器渲染检查因当前隔离环境无法连接预览服务而未完成，未做真实酒馆或真机触摸验收。


## 手机收纳与画面手势（0.15.7-mobile-gestures.0）

手机打开编辑后，顶部只露出靠右的「工具」入口。点开后可用作品、撤销、保存、应用、退出、更多；点「收起」、画面空白处或 Escape 可收起，嵌套菜单一并关闭。收纳栏覆盖在预览上，不再让整行工具长期占用画面高度。PC 保持展开工具栏。

点击画面中的图片素材、名字、时间、头像区/尾部自定义文案或思维入口文字即可选中。手机点选后保持完整预览，点底部「调整」再做数值精调。选中内容可单指拖动；素材可双指缩放，保持当前宽高比例并跟随两指中点。手势结束只记一次撤销，手势取消、失焦、切换对象、退出时丢弃尚未提交的移动。正文和头像仍使用原来的属性设置；正文内容不会被写入或移动。

未选中素材、未选中文字和空白处保留浏览器滚动行为。素材重叠或点不中时，底部「区域 → 调整」中的对象列表仍可选择，再返回预览操作。鼠标拖动同样支持。所有手势只发生在插件虚构预览中，真实酒馆无需额外配合；只有主动应用方案时才按原流程使用保存的样式设置。

本批未增加方案迁移、兼容分支、持续扫描或新的保存格式。测试保存键与 schema 10 不变。开发验证：`npm ci && npm test`，150 项通过，另通过所有模块语法及 `git diff --check`。新增回归覆盖选中/未选中、多指加入与抬起、缩放边界、单位与锚点、父级变换、一次撤销、保存、取消、失焦、退出重开和 PC/手机工具栏切换。

浏览器无法连接隔离预览服务，未完成桌面/320px/390px的渲染检查；DOM 中派发的指针事件不等于真实触摸验收。尚未在真实酒馆、Android 或 iPhone 上验证，仍为公开测试候选。


## 头像设计与固定总高度（0.15.8-avatar-area.0）

头像设计先显示本次预览图。普通头像的大小、比例和圆角独立于边框；边框只控制一条边框，粗细按 0.25 px 调整。移除宽度占比、最大尺寸、额外轮廓和重复倾斜；阴影、旋转和位置独立保留。铺满模式继续只显示取景与渐变，切回普通模式保留普通头像设置。

「头像区总高度」现在决定从卡片内部顶部到头像区底线的实际高度，普通和铺满规则一致。名字、时间、文案、头像与头像区素材不会再把它撑高，原生统计也不会增加头像区高度。内容可移出区域，超出部分裁切；调高后重新露出，配置中的尺寸与坐标不改。头像区与正文之间固定留白为 14 px。原生编辑、更多菜单和尾部操作仍保留功能，不对菜单容器整体裁切。

裁切按文字和图片分别处理，保留图层叠放；拖动或双指缩放时同步裁切。内置起始模板使用明确高度，避免默认名字、时间一开始就被裁掉。

本批不做旧头像数据兼容或迁移。包含已移除头像字段的旧测试方案不会载入，请在更新前导出备份；本批方案重新开始设计。测试保存键与 schema 10 不变，正式版保存和正式仓库未改动。

验证：`npm test` 共 161 项通过，全部 JS/MJS 语法和 `git diff --check` 通过。覆盖普通/铺满、窄/宽布局、长名字、缩小再扩大、裁切逆变换、文字拖动、图层叠放结构、原生控制、退出恢复及保存/撤销。浏览器在当前隔离环境中因 socket 权限无法启动，外部浏览器也无法连接预览服务，因此未完成真实桌面、手机渲染及触摸验收。仍为公开测试版。
