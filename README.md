# ST-Orange-ThemeStudio 真实画布测试版

版本 0.20.0-workbench.0，面向 SillyTavern 1.18.0。电脑和手机使用同一个插件。

## 安装

在酒馆扩展管理中选择「安装扩展」，粘贴：

https://github.com/yanxu-orange/ST-Orange-ThemeStudio-test

正式版与测试版不要同时启用。测试版将当前方案保存在独立的 IndexedDB 数据库中。方案支持 JSON 导入和导出。

## 工作台

手机打开后选择继续草稿、导入、模板或无装饰起稿。底栏提供预览、区域、调整、图层、素材。画布直接使用当前酒馆的聊天、顶栏、输入区与抽屉，编辑面板只处理当前区域。不会创建虚构聊天或替换真实内容。请自行选好原生主题、角色和测试聊天。

手机在「更多 → 调整布局」中进入调节状态，再上下拖动预览与工作台之间的分界。点「完成」锁定本次编辑的比例，「重置」恢复默认；普通状态不会拖动分界。进入输入或弹出软键盘时会结束调节，键盘收起后仍保留刚才的比例。素材区标题旁的铺满按钮可展开素材区，再点一次恢复刚才的比例。切换编辑区域或退出编辑会收起铺满状态，布局比例不写入主题方案。电脑继续直接左右拖动分栏。

设计页面与当前查看页面直接显示在画布上方，电脑和手机都不必进入“更多”找页面。顶部工具仍可收起，更多菜单提供导入、导出、恢复、隐藏滚动条和工坊入口设置。

点击画布中的图片或文字选中，选中后单指拖动位置；选中图片可双指缩放。空白处和未选中内容仍用于滚动。数值按钮和输入框用于精调。整个编辑期间停用酒馆左右滑动翻页，原生点击箭头及纵向滚动保留；退出编辑立即恢复滑动。

修改会实时显示在真实酒馆上，调色盘拖动时即时预览，取消恢复原色，确认后记为一次修改。保存写入现有工坊方案；“应用到酒馆”收起工作台并保留外观，退出编辑或退出应用移除工坊外观并恢复原自定义 CSS 状态。保存仍使用现有 IndexedDB，素材库独立保留，不创建额外备份。

## 真实酒馆画布

沿用此前的屏幕分配与调整布局：电脑左右分栏，手机上下分区，素材区可暂时铺满。聊天和原生抽屉限制在可见画布范围内，内容可纵向滚动；工作台单独滚动。只改变临时布局与样式，不移动或复制原生 DOM。

“设计页面”一级为首页和全局、聊天、预设、API、世界书、设置、背景、扩展、人设、角色及原生回复格式。选原生页面时会打开真实抽屉，直接点击酒馆顶栏也会同步工作台。打开失败不会冒充成功；连续切换以实际页面为准。

首页和全局内分为全局基础与首页设计。全局基础包含界面共用、顶栏与工具、共用输入区；聊天保留消息整体、头像、正文、思维、尾部及其余设置。首页和其他页面的独立设计尚未接入，仅显示明确说明，不把全局控件当成页面专属功能。背景一级指酒馆的背景管理页面，不会自动改换背景图。

选择“首页和全局”不关闭聊天；编辑全局时可用“当前查看”或原生顶栏查看其他页面，设计范围保持全局。要查看首页，请自行使用酒馆原生返回首页，该操作会关闭当前聊天。工坊不自动执行它。

画布中的原生控件是真实控件。手动修改设置或世界书会按酒馆原本的规则生效，不再是隔离示例。工坊本身不会自动选择角色、主题或测试数据，也不会替用户修改世界书内容。

桌面的“390 窄画布”仅收窄可用宽度，不会模拟手机浏览器和操作系统。弹窗、第三方扩展、移动 UI 和实体手机仍需实际验收。

## 界面共用外观

在「首页和全局 → 全局基础 → 界面共用」编辑一套全局共同外观。保持这个设计范围后，可查看真实设置、世界书等页面检查效果，不会暗中改成编辑该页。

- 界面文字：字体、字号、主辅文字色和强调色，支持现有字体库与字体直链。
- 面板：底色、透明度、边框及圆角，包含世界书条目卡片。
- 分区标题：文字色、底色、字号、字重及圆角。
- 按钮：文字、底色、边框、圆角和悬停/选中状态。危险按钮保留警示色。
- 输入与选择：输入框、多行文字、原生下拉及 Select2 的颜色、边框、圆角、焦点。复选框与滑块使用界面强调色，只读与禁用状态保持可辨认。

共用外观随当前方案实时显示、撤销、保存和 JSON 导入导出。初始文字、面板和强调色取自当前模板；不增加独立启用步骤。手机输入/选择控件至少为 16px，避免聚焦时页面放大；更大的设定仍会生效。设置和世界书也可用「更多 → 调整布局」调整手机预览与编辑面板比例。

编辑与应用期间，共用样式作用于原生抽屉、弹窗、菜单及 Select2 浮层，后打开的控件也会生效；不改写设置或世界书数据。聊天正文、顶栏及输入区继续使用已有独立设计。停止应用移除本方案样式并恢复原自定义 CSS 的启用状态。应用期间原自定义 CSS 会按既有流程停用，因此未覆盖部分并不会继续叠加原来的小猫等主题。

这是完整全局美化的第一步。各页面独有布局、标题插画、通知及第三方扩展内部专门适配尚未加入。导出仍是工坊方案，不是可直接导入酒馆原生主题栏的主题文件。

## 工坊入口

在“更多 → 工坊入口”选择魔棒、扩展或悬浮入口，可以多选，至少保留一个实际可用入口。三种入口共用同一个打开流程；手机继续进入作品设置。魔棒与扩展内也可返回编辑、退出已应用方案。

入口选择与悬浮位置仅保存在本机浏览器，不进入主题方案。关闭悬浮入口后，退出编辑、应用和刷新不会自行恢复它，也不会额外弹出应用浮条。入口设置写入失败会明确提示并保留之前的选择。

## 图层

图层面板只在支持的区域启用，显示当前区域的头像、名字、时间、文案和图片。列表上方的素材覆盖下方素材，当前选中项高亮。使用上移、下移、置顶、置底调整顺序，点击编辑返回属性设置。

头像区图片即使定位在头像上，也可独立排到文字上方或下方。每个区域使用唯一顺序，不需要填写层级数字。

## 头像

先选择统一设计或分别设计，再设置显示方式。普通头像按比例、大小、圆角、边框、阴影、位置、取景的顺序调整。铺满模式提供取景与渐变。

工作台直接使用酒馆当前聊天头像，不再提供虚构预览头像上传入口；头像来源始终由酒馆管理。

头像区高度固定，区域外的内容被裁切，内部素材不会撑高区域。头像大小独立于头像边框，没有额外的整体缩放控件。

## 卡片与文字

手机卡片宽度自动填满聊天区减去两侧留白的空间。留白为零即贴齐聊天区；电脑仍可设置最大宽度。

头像区和尾部区的自定义文案通过「选择文案」切换，可分别应用于 AI、用户或双方。字体链接使用字体文件直链，在对应文字的字体设置中载入。

正文左右留白从卡片内边缘计算，设为零不预留横向空间。

## 其余设置

编辑、更多各自设置位置。楼层信息分别设置楼层号、生成时长和 Token 位置。回复翻页可选紧凑或左右两端排列。楼层号可设置前缀和后缀，清空前缀即可隐藏 #。

编辑和更多按钮可使用文字或图片，图片按图标大小完整显示。输入区原生横排将文字与按钮垂直居中，多行输入仍会增高。

## 素材库

素材库是独立入口，所有页面都可浏览、上传和管理，按「图片 / 图形 / 图标 / 字体」分开，上传图片与上传图标各自保存。

使用图片或图形前显示实际支持的目标：聊天的头像区、消息整体、思维入口、思维正文、尾部，以及首页和全局的共用输入区。没有有效目标时不自动放入头像区。图标明确选择顶栏、共用输入区或消息按钮；字体仍从具体文字控件选用。尚未支持的页面不提供装饰放置和图层编辑。正文、顶栏及消息原生按钮没有独立排序图层时，图层入口不可用。

上传图片或保存 HTTP(S) 图片直链，先存入「我的素材」，再点击「使用素材」放入当前区域。素材库保存在当前浏览器，与当前方案独立。

上传无需选择压缩参数。较大的静态图会尝试同尺寸高质量 WebP，只有节省至少 10% 且 16 KiB 时采用；小图、低收益图以及 GIF、APNG、动态 WebP 保留输入素材。只存一份主图，不另存原图。动画不支持裁剪，避免变成静态图片。现有作品与素材不会被自动改写。

装饰图片与素材库小图按实际显示大小和屏幕像素比按需生成临时小图，较大显示会重新取足够大的版本；临时图不进入保存或导出，不跨设备沿用。GIF、APNG、动态 WebP 及外链不做静态缩图。素材库仅为可见项目处理小图，编码逐张异步执行；浏览器支持时在 Worker 中执行。CSS 背景和原生酒馆头像仍使用原有来源。

测试版新上传单张最多 16 MiB、1600 万像素，先检查尺寸再解码，方案校验与导入导出使用同一个图片容量标准。这是有限的试验边界，不是手机内存安全保证；大量图片及动画仍可能占用较多内存，实体手机尚待验证。WebP 是有损压缩，保留透明不等于整体无损。

导出方案只带已使用的上传图片；外链保留为原链接。素材库不随方案导出，也不会跨设备同步。图片直链需要在目标设备上可以访问。每条自定义素材可从库中删除，删除不影响已放入方案的图片。

通用内置图片库收录五套主题的 9 件素材：黑粉紫双蝶、春日双花、小猫双猫、雪间邮戳、慕夏鸢尾和金线。按贴纸、花饰、邮戳、边框分组。图片已随扩展提供，不依赖原主题外链；方案保存已使用的内置素材标识，导入到包含本组资源的扩展版本即可继续使用。雪间邮戳是透明底图，不包含动态时间和弧形文字。

小猫模板仍使用自己的窗景、纸片等原有资源，它们不再混入通用内置列表。打开已使用的模板素材时会保留当前选项，只有明确选择其他图片才替换；不改写已有作品或模板。

内置形状包含矩形、星形和爱心，按宽高与旋转、外观、位置顺序编辑，支持纯色、双色渐变与渐变方向；矩形另有圆角设置。

当前方案保存在本浏览器的 IndexedDB 中，点击“保存方案”会替换上次保存。显示“已保存方案”后刷新，可以继续编辑。导入只替换当前草稿，仍需点击保存；素材库与方案独立，删除库中原图不影响方案内图片。

浏览器存储空间仍由设备、网站权限及浏览器决定。实际写入失败时会显示原因，原已保存方案不变；可释放不需要的存储后重试，或手动导出当前方案。导入没有额外的文件总大小拦截，大文件仍受设备内存影响。清除网站数据会同时清除本机方案与素材库。

## 图标库

「图标」分为「内置 / 我的」。首批 31 枚使用五套主题的原始 SVG：小猫与雪间各 9 枚顶栏，猫爪与圆点更多、星芒与慕夏魔棒，以及五款发送和四款配套停止。雪间原主题没有独立停止 SVG，不补造配套款，可保留原生停止或另选图标。来源见 `materials/icons/SOURCES.json`。

在顶栏、输入工具与发送、消息编辑与更多的图形设置中选择「从图标库选择」，也可在素材区先指定目标按钮。选用后调整大小、保留原色或统一染色；统一染色支持与图形相同的纯色、双色渐变和方向设置。内置图标默认使用主题强调色，上传图标默认保留原色。顶栏与输入支持单独尺寸，设为跟随区域时沿用该区域尺寸；消息按钮沿用各自图标大小。

统一染色根据透明轮廓填色，不会自动抠图。透明背景适合染色；带实色背景会连背景一起变色，多色内容会合为统一配色。上传支持 PNG / APNG、JPG、WebP、GIF，暂不支持 SVG；沿用图片的 16 MiB、1600 万像素上传边界。

我的图标只保存在本浏览器。使用后把图片复制进方案，删除库记录不影响已用图标；保存、导入和导出包含已选图标及配色、尺寸，不携带整座图标库。内置图标按标识保存，目标扩展需要包含同批资源。图标不改变按钮的实际业务，发送和停止的显隐仍由酒馆管理。

## 字体库

在素材库中保存字体名称与字体文件直链，在名字、文案、正文等字体设置中从「我的字体」选用。字体库保存在当前浏览器；方案携带已选用的字体链接，移除库中记录不会改变方案。

## 开发验证

运行 `npm ci && npm test`。自动测试包含原生消息节点与监听器保留、进出编辑恢复、方案保存/导出、原生抽屉导航、整个编辑期的滑动拦截、选中素材手势和调色预览回滚。

实时更新按动画帧合并。颜色类变更更新样式，不逐条重建聊天；几何变化复用已有消息和素材节点；单条流式消息只更新受影响消息。测试覆盖长聊天的节点访问数量，DOM 测试耗时不能等同实体手机帧率。

此前真实画布版本已在独立官方 SillyTavern 1.18.0（51ad27f）与全新测试数据下完成前端编译、服务启动、HTTP 和原生 HTML 结构检查，并在桌面 Chromium 真实页面验收：调色实时预览/取消/确认/撤销、名字及图片素材鼠标拖动、设置抽屉与工作台独立滚动、世界书抽屉、390 窄画布、保存后刷新恢复、应用与退出还原。测试使用自带 Dark Lite 主题及 Seraphina 示例，工坊开启后叠加当前方案。

桌面鼠标验收不等于手机触摸验收。Android/iPhone 的单指拖动、双指缩放、整个编辑期的左右手势拦截及退出恢复仍需真机确认；手机上下分区目前仅有自动化布局测试。软键盘、原生弹窗和第三方扩展组合也尚待设备验证。仍为公开测试候选，未改动用户设备或生产项目。

内置素材及字体许可随仓库提供。

本批工作台结构调整的真实桌面检查已覆盖一级 11 项、全局设计与当前查看页面分离、预设/API/世界书/设置/背景/扩展/人设七个抽屉同步、未接入说明及图层禁用和素材入口。角色、回复格式、素材目标完整流程、入口隐藏后重进及窄视口尚待本批实页复核，相关行为有自动化测试。后半实页测试通道未完成，不能视为全套实机验收通过。实体手机仍未测试。
