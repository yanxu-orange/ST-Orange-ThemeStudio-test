# ST-Orange-ThemeStudio 手机隔离测试版

版本 0.18.0-workbench.0，面向 SillyTavern 1.18.0。电脑和手机使用同一个插件。

## 安装

在酒馆扩展管理中选择「安装扩展」，粘贴：

https://github.com/yanxu-orange/ST-Orange-ThemeStudio-test

正式版与测试版不要同时启用。测试版将当前方案保存在独立的 IndexedDB 数据库中。方案支持 JSON 导入和导出。

## 工作台

手机打开后选择继续草稿、导入、模板或无装饰起稿。底栏提供预览、区域、调整、图层、素材。预览始终展示整体效果，编辑面板只处理当前区域。

手机在「更多 → 调整布局」中进入调节状态，再上下拖动预览与工作台之间的分界。点「完成」锁定本次编辑的比例，「重置」恢复默认；普通状态不会拖动分界。进入输入或弹出软键盘时会结束调节，键盘收起后仍保留刚才的比例。素材区标题旁的铺满按钮可展开素材区，再点一次恢复刚才的比例。切换编辑区域或退出编辑会收起铺满状态，布局比例不写入主题方案。电脑继续直接左右拖动分栏。

顶部工具可收起，更多菜单提供「预览页面」、导入、导出、恢复及隐藏滚动条。插件入口可以拖动到屏幕两侧，位置保存在当前浏览器。

点击预览中的图片或文字选中，单指拖动位置；选中图片可双指缩放。空白处和未选中内容仍用于滚动。数值按钮和输入框用于精调。修改后点击保存；应用将样式用于当前酒馆，停止应用可恢复。

## 页面预览

在现有「更多 → 预览页面」同级切换聊天、设置、世界书，不增加第二个工具栏。切换后菜单收起，返回聊天会恢复原来的编辑区域与位置。其他页面标记为待接入，不能选用。

设置包含原生结构的分组、下拉、单行/多行输入、勾选和滑块；世界书包含展开、折叠、停用条目、关键字、正文及本地示例搜索。分组和全局参数仍在所属页内滚动、展开，不拆成一级入口，也不把同页分区伪装成子页面。当前三页没有额外的子页面选择。

设置和世界书使用虚构数据。控件可用于检查焦点与交互外观，变化只保留在本次预览里；不读取或修改真实设置、世界书，不保存到主题方案。其外观编辑尚未接入。保存、导出和应用仍处理已有的聊天主题方案。

结构依据：[SillyTavern 1.18.0 用户设置](https://github.com/SillyTavern/SillyTavern/blob/1.18.0/public/index.html#L4868)、[世界书条目模板](https://github.com/SillyTavern/SillyTavern/blob/1.18.0/public/index.html#L7136)、[世界书样式](https://github.com/SillyTavern/SillyTavern/blob/1.18.0/public/css/world-info.css)。这是代表性预览，不是完整复制酒馆设置。窄预览根据实际容器宽度转为纵向布局。

## 图层

图层面板显示当前区域的头像、名字、时间、文案和图片。列表上方的素材覆盖下方素材，当前选中项高亮。使用上移、下移、置顶、置底调整顺序，点击编辑返回属性设置。

头像区图片即使定位在头像上，也可独立排到文字上方或下方。每个区域使用唯一顺序，不需要填写层级数字。

## 头像

先选择统一设计或分别设计，再设置显示方式。普通头像按比例、大小、圆角、边框、阴影、位置、取景的顺序调整。铺满模式提供取景与渐变。

打开工作台时读取当前聊天头像。预览图片入口默认折叠，可上传本次预览头像；预览图不进入方案。应用时使用酒馆当前头像。

头像区高度固定，区域外的内容被裁切，内部素材不会撑高区域。头像大小独立于头像边框，没有额外的整体缩放控件。

## 卡片与文字

手机卡片宽度自动填满聊天区减去两侧留白的空间。留白为零即贴齐聊天区；电脑仍可设置最大宽度。

头像区和尾部区的自定义文案通过「选择文案」切换，可分别应用于 AI、用户或双方。字体链接使用字体文件直链，在对应文字的字体设置中载入。

正文左右留白从卡片内边缘计算，设为零不预留横向空间。

## 其余设置

编辑、更多各自设置位置。楼层信息分别设置楼层号、生成时长和 Token 位置。回复翻页可选紧凑或左右两端排列。楼层号可设置前缀和后缀，清空前缀即可隐藏 #。

编辑和更多按钮可使用文字或图片，图片按图标大小完整显示。输入区原生横排将文字与按钮垂直居中，多行输入仍会增高。

## 素材库

素材区按「图片 / 图形 / 图标 / 字体」分开，上传图片与上传图标各自保存。

上传图片或保存 HTTP(S) 图片直链，先存入「我的素材」，再点击「使用素材」放入当前区域。素材库保存在当前浏览器，与当前方案独立。

上传无需选择压缩参数。较大的静态图会尝试同尺寸高质量 WebP，只有节省至少 10% 且 16 KiB 时采用；小图、低收益图以及 GIF、APNG、动态 WebP 保留输入素材。只存一份主图，不另存原图。动画不支持裁剪，避免变成静态图片。现有作品与素材不会被自动改写。

预览头像、装饰图片与素材库小图按实际显示大小和屏幕像素比按需生成临时小图，较大显示会重新取足够大的版本；临时图不进入保存或导出，不跨设备沿用。GIF、APNG、动态 WebP 及外链不做静态缩图。素材库仅为可见项目处理小图，编码逐张异步执行；浏览器支持时在 Worker 中执行。CSS 背景和原生酒馆头像仍使用原有来源。

测试版新上传单张最多 16 MiB、1600 万像素，先检查尺寸再解码，方案校验与导入导出使用同一个图片容量标准。这是有限的试验边界，不是手机内存安全保证；大量图片及动画仍可能占用较多内存，实体手机尚待验证。WebP 是有损压缩，保留透明不等于整体无损。

导出方案只带已使用的上传图片；外链保留为原链接。素材库不随方案导出，也不会跨设备同步。图片直链需要在目标设备上可以访问。每条自定义素材可从库中删除，删除不影响已放入方案的图片。

通用内置图片库收录五套主题的 9 件素材：黑粉紫双蝶、春日双花、小猫双猫、雪间邮戳、慕夏鸢尾和金线。按贴纸、花饰、邮戳、边框分组。图片已随扩展提供，不依赖原主题外链；方案保存已使用的内置素材标识，导入到包含本组资源的扩展版本即可继续使用。雪间邮戳是透明底图，不包含动态时间和弧形文字。

小猫模板仍使用自己的窗景、纸片等原有资源，它们不再混入通用内置列表。打开已使用的模板素材时会保留当前选项，只有明确选择其他图片才替换；不改写已有作品或模板。

内置形状包含矩形、星形和爱心，按宽高与旋转、外观、位置顺序编辑，支持纯色、双色渐变与渐变方向；矩形另有圆角设置。

当前方案保存在本浏览器的 IndexedDB 中，点击“保存方案”会替换上次保存。显示“已保存方案”后刷新，可以继续编辑。导入只替换当前草稿，仍需点击保存；素材库与方案独立，删除库中原图不影响方案内图片。

浏览器存储空间仍由设备、网站权限及浏览器决定。实际写入失败时会显示原因，原已保存方案不变；可释放不需要的存储后重试，或手动导出当前方案。导入没有额外的文件总大小拦截，大文件仍受设备内存影响。清除网站数据会同时清除本机方案与素材库。

## 图标库

「图标」分为「内置 / 我的」。首批 31 枚使用五套主题的原始 SVG：小猫与雪间各 9 枚顶栏，猫爪与圆点更多、星芒与慕夏魔棒，以及五款发送和四款配套停止。雪间原主题没有独立停止 SVG，不补造配套款，可保留原生停止或另选图标。来源见 `materials/icons/SOURCES.json`。

在顶栏、输入工具与发送、消息编辑与更多的图形设置中选择「从图标库选择」，也可在素材区先指定目标按钮。选用后调整大小、保留原色或统一染色；统一染色支持与图形相同的纯色、双色渐变和方向设置。内置图标默认使用主题强调色，上传图标默认保留原色。顶栏与输入支持单独尺寸，设为跟随区域时沿用该区域尺寸；消息按钮沿用各自图标大小。

统一染色根据透明轮廓填色，不会自动抠图。透明背景适合染色；带实色背景会连背景一起变色，多色内容会合为统一配色。上传支持 PNG / APNG、JPG、WebP、GIF，暂不支持 SVG；沿用图片的 16 MiB、1600 万像素上传边界。

我的图标只保存在本浏览器。使用后把图片复制进方案，删除库记录不影响已用图标；保存、导入和导出包含已选图标及配色、尺寸，不携带整座图标库。内置图标按标识保存，目标扩展需要包含同批资源。图标不改变按钮的实际业务，发送和停止的显隐仍由酒馆管理。

## 字体库

在素材库中保存字体名称与字体文件直链，在名字、文案、正文等字体设置中从「我的字体」选用。字体库保存在当前浏览器；方案携带已选用的字体链接，移除库中记录不会改变方案。

## 开发验证

运行 `npm ci && npm test`。自动测试覆盖 DOM、存储、图层顺序、角色范围、手势、导入导出和预览/应用渲染规则。

尚未完成真实酒馆、Android/iPhone 及浏览器视觉与触摸验收。仍为公开测试版。

内置素材及字体许可随仓库提供。
