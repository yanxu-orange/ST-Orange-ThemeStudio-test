# ST-Orange-ThemeStudio 真实画布测试版

版本 **0.24.0-page-basics**，面向 SillyTavern 1.18.0。电脑和手机使用同一个插件。

## 安装

在酒馆扩展管理中选择「安装扩展」，粘贴：

https://github.com/yanxu-orange/ST-Orange-ThemeStudio-test

正式版与测试版不要同时启用。测试版在本浏览器独立保存方案和素材，支持方案 JSON 导入、导出。

## 工坊入口

魔棒使用与兰台相同的原生「图标 + 文字」列表行，不再嵌套大按钮。扩展面板使用紧凑的原生标题行，点击直接进入工坊；不会新增一层折叠页。应用后可继续编辑或退出工坊应用。三个入口的浏览器本地开关保持不变。

入口蝴蝶复用仓库已有的 `materials/shared/black-rose-butterfly.webp`，对应素材库「黑粉紫 · 黑玫撕裂蝶」，不引入新素材或外部图片请求。

## 工作台结构

打开工坊直接进入编辑。顶栏保留全屏预览、撤销、素材库、保存、应用和更多，另可单独收起顶部工具栏；导入、导出、恢复已保存、模板、入口和布局设置放在更多里。

编辑面板按「编辑范围 → 区域 → 对象 → 属性」排列。支持图层的区域在区域旁显示图层按钮，进入后可返回属性。没有重复的区域导航、查看页面下拉或手机底部导航。

编辑范围包括首页和全局、聊天、预设、API、世界书、设置、背景、扩展、人设、角色和回复格式。

- **首页和全局**：全局基础、顶栏与工具、共用输入区、页面头部、首页设计。
- **聊天**：卡片整体、头像区、正文、思维、尾部区、消息控件。
- 全局基础分为界面文字、面板、分区标题、按钮、输入与选择。
- **预设、API、世界书、设置、背景、扩展、人设、角色、回复格式**：均有页面基础与页面头部。基础外观按组跟随全局或单独设置，并可选用页面背景图片。
- **设置、世界书**另有内容分组与条目编辑。其余页面的专属列表、卡片与布局未开放；首页设计的其他功能仍未接入。

### 与酒馆各自切换

工坊只切换编辑内容，酒馆原生顶栏只切换实际页面，两者互不联动。编辑全局时可以打开真实设置或世界书查看效果；切到工坊的聊天编辑也不会关闭世界书。切回某个编辑范围时保留其上次选中的区域与对象。

画布直接使用当前酒馆的聊天、顶栏、输入区和抽屉，不复制聊天或替换真实内容。角色、聊天内容、API、世界书业务及原生页面导航仍由酒馆管理。工坊不会替用户选择角色、修改世界书内容或关闭当前聊天。

### 电脑与手机

电脑左右分栏，拖动分界可调整宽度。手机上下分区，面板内只显示当前编辑层级；全屏预览隐藏属性面板，再点返回编辑恢复。

点击顶部「收起」只收起工具栏，属性面板仍可继续编辑，酒馆顶栏回到原位置。临时工坊入口可拖动并贴在左右边缘，点它展开工具栏；这个入口不受退出编辑后的悬浮入口开关影响。更多菜单的短按钮两列排列，长控件独占一行，小屏内可滚动；「工坊首页」用于继续当前草稿、导入或选择新起点。

手机在「更多 → 调整工作台高度」中上下拖动分界，点完成退出调整，重置恢复默认比例。输入或弹出软键盘时会结束调整。素材区可以临时铺满，再收起回原比例。比例属于本次工作台布局，不写入主题方案。

点击真实画布中的图片或文字选中，再单指拖动；选中图片支持双指缩放。空白处和未选中内容仍用于滚动，数值输入与按钮用于精调。编辑期间停用酒馆左右滑动翻页，保留原生箭头点击和纵向滚动，退出即恢复。

## 已有编辑能力

### 全局与原生控件

- 界面文字：字体、字号、主辅文字色、强调色。
- 面板：底色、透明度、边框、圆角，包括世界书条目卡片。
- 分区标题：文字色、底色、字号、字重、圆角。
- 按钮：文字、底色、边框、圆角、悬停与选中状态；危险按钮保留警示色。
- 输入与选择：输入框、多行文字、原生下拉及 Select2 的颜色、边框、圆角、焦点；复选框与滑块使用强调色。
- 顶栏与输入区：已有区域外观、按钮文字或图形、尺寸和配色。

共用外观覆盖原生抽屉、弹窗、菜单和后打开的 Select2 浮层。手机输入和选择控件至少为 16px，避免聚焦放大。九个原生页面均可独立覆盖基础外观；页面独有布局、第三方扩展内部专门适配尚未实现。

### 页面头部

在「编辑范围」选择要设计的页面，再选「区域 → 页面头部」。支持近期聊天首页、预设、API、世界书、设置、背景、扩展、人设、角色和回复格式，共十页。正式聊天页继续使用消息卡片编辑。

- 每页独立保存图片与设置，默认关闭。点击「选择图片」进入现有素材库，支持内置素材、上传图片和图片直链，选用后自动开启；返回或 Escape 取消选用。
- 宽度跟随所在页面。选择「指定高度」可设 40–600px，并调整「铺满区域 / 完整显示」及水平、垂直取景；选择「按图片比例」则自动计算高度。
- 关闭时保留图片与尺寸，重新开启即可继续使用；移除图片可撤销。设置随方案保存、导出和导入。
- 「顶部留白」「左右留白」可按页分别调节，默认 0，贴齐页面头部容器边缘；图片取景保持独立。
- 预设、角色、背景的头图位于原生控件之前，随整页滚动。背景两个标签共用一个头部，原生回顶与角色/群聊定位转接到同一滚动页面；关闭头图后恢复原生滚动。首页只在近期聊天欢迎页显示。

### 各页面独立外观

先在「编辑范围」选择预设、API、世界书、设置、背景、扩展、人设、角色或回复格式，再选择「页面基础」。编辑范围仍不替代酒馆的原生切页，请在真实页面查看效果。

- **页面基础**：界面文字、面板、分区标题、按钮、输入与选择，共用同一套属性控件。每一组可「跟随全局」或「单独设置」。开始单独设置时复制当前外观，恢复跟随后再次随全局更新；各页互不覆盖。
- **设置分组**：对应原生用户设置的主题、界面与高级设置三列，单独调整底色、透明度、边框和圆角。默认不额外覆盖原生分组；本页面板开启单独设置后，分组可继续跟随它或再单独设置。
- **世界书条目**：实际条目卡片与条目标题分别设置。卡片默认跟随本页面板，条目标题默认沿用页面外观；本页分区标题单独设置后，条目标题可跟随它或再单独设置。
- **背景图片**：页面面板、设置分组、世界书条目卡片可调用现有图片素材库，调整铺放方式与水平/垂直取景。取消不改方案，选中返回原属性。背景不增加装饰节点，不盖住输入、按钮、折叠和拖动操作。
- 原生下拉与 Select2 沿用本页输入/选择配色；挂在页面之外的 Select2 浮层按来源控件归属，不影响其他页面的下拉。复选框与滑块的强调色在「界面文字」里调整。
- 删除等危险按钮保留警示色。按钮名称、图标、业务行为、世界书内容和条目顺序不由本次外观编辑改写。

页面素材提供背景取景，不含任意拖拽装饰图层或逐个业务按钮换图标。长按、手机原生文件选择、软键盘和实体设备表现仍需真机检查。

### 聊天卡片

保留卡片背景、尺寸、留白、边框和阴影；普通头像的比例、大小、圆角、边框、阴影、位置、取景，以及铺满头像的取景与渐变。头像始终来自真实酒馆，工坊不另管头像来源。

头像区和尾部区支持独立文案，可应用于 AI、用户或双方。名字、时间、文案、正文保留独立文字样式与字体设置。头像区高度固定，超出区域的内容裁切；头像大小独立于边框。

手机卡片宽度按聊天区减去两侧留白计算；电脑仍可设置最大宽度。正文留白从卡片内边缘计算，左侧与右侧默认均为 10px。保留思维入口、思维正文、尾部、消息编辑与更多、楼层号、生成时长、Token、回复翻页的现有设置。

### 图层

支持卡片整体、头像区、思维、尾部和共用输入区。当前区域的头像、名字、时间、文案、图片按实际顺序显示，使用上移、下移、置顶、置底调整，不需要填写层级数字。没有独立图层的区域不显示图层入口。

## 素材：管理与使用分开

顶栏素材库按图片、图形、图标、字体分类，只浏览、添加、编辑或移除资源，不要求选择应用区域，也不会改变方案。

在具体区域或属性中点击添加图片、选择素材、从字体库选择，才进入选用模式。调用位置已确定目标，选择后立即回到原区域；返回或 Escape 取消，不更改对象。浏览期间切换真实酒馆页面不会更换素材目标。

### 图片和图形

内置图片直接以缩略图展示；我的图片支持上传、HTTP(S) 直链和删除。区域调用可选用图片或矩形、星形、爱心，图形保留宽高、旋转、纯色、双色渐变、渐变方向和矩形圆角。

内置图片包括五套主题的 9 件通用素材：黑粉紫双蝶、春日双花、小猫双猫、雪间邮戳、慕夏鸢尾和金线，随扩展提供。模板自己的窗景、纸片等资源仍保留在原作品，不混入通用列表。

上传支持 PNG/APNG、JPG、WebP、GIF，单张最多 16 MiB、1600 万像素。较大静态图仅在节省至少 10% 且 16 KiB 时采用同尺寸高质量 WebP；小图、低收益图和动画保留输入素材。只存一份主图，动画不裁剪。显示用临时小图不进入保存和导出。

素材库与方案独立。删除库记录不影响已经放入方案的图片。方案导出只包含已使用的图片；外链仍为原链接，不携带整座素材库。图片与动画的实际内存占用取决于设备。

### 图标

图标分内置和我的，保留 31 枚原主题 SVG；来源见 `materials/icons/SOURCES.json`。上传支持 PNG/APNG、JPG、WebP、GIF，暂不支持自定义 SVG。

顶栏、输入工具与发送的「按钮图形」把「原生／自定义」与「选择素材」放在同一行。按钮直接打开现有图片和图标库，选中后自动切到自定义并显示「更换」；返回或取消不改方案。消息编辑与更多使用同样的选择方式，并保留文字模式。选用图标后可以调整尺寸、保留原色或统一染色，支持纯色与双色渐变。图标只改变外观，不改变发送、停止等原生业务。

### 字体

字体库使用「名称 + 文件直链 + 字重」管理，每条显示字体预览并可编辑或移除。在具体文字属性中调用后返回该属性，保留直接填写字体链接的方式。

## 保存、应用与入口

修改实时显示在真实酒馆中。调色时实时预览，取消恢复原色，确认后记为一次修改。保存替换本浏览器已保存方案；导入只替换当前草稿，仍需保存。

应用到酒馆会收起工作台并保留外观，不再显示悬浮状态条；通过原有工坊入口继续编辑或退出应用。退出编辑或停止应用会移除工坊外观，恢复原自定义 CSS 的启用状态。应用期间原自定义 CSS 按既有流程停用。导出的是工坊方案，不是酒馆原生主题文件。

魔棒、扩展、悬浮入口都保留，使用同一打开流程。「更多 → 工坊入口」可以多选，至少保留一个可用入口。入口选择和悬浮位置仅存本机，不进入主题方案；关闭悬浮入口后不会自行恢复。

浏览器存储写入失败会显示原因，原已保存方案不变。清除网站数据会清除本机方案与素材库。
