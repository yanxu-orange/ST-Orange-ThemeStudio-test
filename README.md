# ST-Orange-ThemeStudio 手机隔离测试版

版本 0.15.4-mobile-color-background.0。面向 SillyTavern 1.18.0；电脑和手机使用同一个插件。

## 安装
在酒馆扩展管理中选择「安装扩展」，粘贴：

https://github.com/yanxu-orange/ST-Orange-ThemeStudio-test

如已安装正式 ThemeStudio，先导出方案备份、停用正式版并刷新，再启用此测试版。两个版本不可同时启用。

本测试版使用独立保存键 `orange.theme-lab.mobile-test.v1`，不会读取或覆盖正式版保存。可用 JSON 导入/导出方案，跨设备不会自动同步。

122 项自动检查通过，但尚未完成真实酒馆、手机视觉与触摸验收。请勿作为稳定发布版使用。

手机底栏切换预览/区域/调整/素材。选区域后点选装饰素材，再按住选中素材拖动；空白处用于滚动，滑条和数值用于精调。头像和文字暂不支持拖动。修改后需主动保存。

内置素材及字体许可随仓库提供。

## 手机流程更新

手机打开先选择继续草稿、导入、模板或无装饰起稿。顶部保留作品、撤销、保存、应用、退出、更多；底栏重复点选可收起面板。返回作品不会重置草稿，无装饰起稿须确认替换且不会自动保存。

无装饰起稿仍使用工具基础布局与颜色，并非恢复酒馆原生样式。桌面沿用原布局。保存键与 schema 10 不变。

## 隐藏滚动条

手机「更多 → 方案 → 隐藏滚动条（仍可滚动）」；桌面在「方案」菜单。旧方案缺省开启，关闭可恢复原有样式；保存方案才保留选择。

作用于工作台及应用期间的酒馆原生滚动条，并适配已识别的兰台开放 shadow 面板。不覆盖其他未知或封闭 shadow、iframe、独立 App 及自绘滚动条。不禁用滚动，不修改其他插件源码；退出后清理自有临时样式。

真实手机滚动和绘制效果尚待验收。

## 配色与酒馆背景

新增工具内配色面板，确认后才提交本次颜色修改。

新方案透出酒馆当前背景，不另设画布背景色或图片；请在酒馆背景菜单换图。卡片底色、透明度和玻璃模糊独立保留。跨设备导入不会携带酒馆壁纸。

旧方案保留原纯色画布，可在整体区域点击「改为跟随酒馆背景」，支持撤销，保存后记住。未进行真实手机视觉验收。

## 文字与位置控件整理

头像区基础页面不再展示文字整体对齐和整体偏移控件，名字、时间、自定义文案仍可独立编辑；旧方案已有整体偏移保持不变。

位置数值旁新增减/加微调按钮，按原步长移动并支持逐次撤销。层次按钮改为「上移一层 / 下移一层」，仅改变叠放顺序，不改变画面位置。本次沿用版本号，以仓库提交区分更新。
